# PL Analyzer Pro v1.1.6 勾选曲线导出与峰筛选发布说明

## 新增

### 勾选曲线导出 Excel（完整数据）

- 左侧样品列表新增 `导出 Excel…` 按钮；`文件 → 导出 → 导出已勾选曲线…`
  和主工具栏的同一动作（`Ctrl+E`）等价。
- 只导出样品列表中**已勾选**的曲线，未勾选的曲线完全不进入工作簿。
- 每条曲线一个工作表，写入该曲线的**完整数据**：`Wavelength (nm)` 与
  `Intensity (a.u.)` 两列、全部采样点（按存储顺序，不抽稀、不排序、不补充计算），
  数值即导入的原始强度，不做归一化、偏移、平滑或基线处理。
- 工作簿**不含汇总/基本信息表**：表名取自样品名（非法字符替换、31 字符截断、重名自动
  加序号），打开即可直接取数或重新作图。
- 当存在保留峰时，末尾追加 `Peaks` 表，只列出已勾选的峰；没有保留峰时不生成。
- 超过 Excel 单表行数上限的长光谱按 `1,048,000` 行拆分成后续工作表，不丢点。
- 导出仍然走同目录临时文件 + 原子替换，失败不会留下半个工作簿。

### 寻峰结果勾选与忽略

- Raw Peak 表新增首列 `勾选`，逐峰决定保留还是忽略。
- 取消勾选的峰不再标注在图上、不参与 `复制勾选`、不进入任何峰表导出。
- `全选` / `全部取消` 批量修改当前表中的全部峰。
- 忽略决定按“样品 ID + 峰位（6 位小数）”记录：
  - 重跑寻峰后，峰位不变的峰继续保持原来的勾选状态；
  - 删除样品时对应的勾选记录一起丢弃；
  - 保存工程时写入 `extensions.ignored_peaks`，重新打开 `.plproj` 后恢复。
- 峰表导出（`导出…`）同样只写保留峰；一个都没有时给出提示而不是导出空表。

### 峰表按列排序

- 点击 `峰位`、`峰高` 列标题按数值升序排列，再次点击切换为降序；`样品`、`材料`、
  `峰`、`FWHM`、`突出度`、`质量` 列同样可排序，`勾选` 列不参与排序。
- 排序按真实数值/文本值比较，不按显示字符串（如 `620.8292` 与 `1000.0000` 不会错序）。
- 排序只改变视图行序；结果本身、导出顺序和峰身份不变。刷新/重跑寻峰后当前排序保持，
  勾选状态跟随对应峰移动。

### 复制勾选峰

- `复制勾选` 一次复制所有保留峰，制表符分隔，可直接粘贴进 Excel 或报告。
- 每行只有三列：`样品`、`峰位`（数值后带 `nm` 单位）、`峰高`。
  例：`AGA017	872.3302 nm	6.67734`。
- **不带表头行**，也**不包含**材料、峰序号、FWHM、突出度、勾选状态或质量标记等列。
- 行的顺序与当前表格视图一致，粘贴结果和屏幕所见相同；没有已勾选峰时不写入剪贴板。

## 兼容性

- `.plproj` 顶层 `schema_version` 仍为 3。勾选状态放在版本化的自由扩展字段
  `extensions.ignored_peaks` 中，旧版本读取时会忽略该键，不会导致工程损坏。
- 科学算法、材料目录、导入器和拟合结果契约不变；勾选与排序只影响呈现与导出选择。

## 验证

- 152 项 pytest 通过（新增曲线导出、峰勾选、排序与本地化复制测试）。
- Ruff lint 与 format 检查通过。
- 中文界面确认新控件文本：`导出 Excel…`、`导出已勾选曲线(&C)…`、`勾选`、
  `复制勾选`、`全选`、`全部取消`。
- 手工验收：导入 OPJ → 勾选部分曲线 → 导出 Excel → 核对每条曲线工作表点数与首尾数值；
  取消勾选一个峰后确认图上标记消失、复制内容不含该峰；点击 `峰高` 两次确认降序且
  勾选状态跟随；保存并重开工程确认勾选状态保留。
